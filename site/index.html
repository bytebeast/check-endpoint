Features

Everything curl -w wishes it did.

Client-side, per-phase evidence for the endpoints you don't control. When the owner says "looks fine on our end", point at the column that isn't.

live

Live streaming output

Each phase prints as it completes. A hang stalls visibly at the phase that's stuck.

deltas

Per-phase deltas

Every column is that phase alone, not a running total. Only TOTAL_TIME accumulates.

--stats

Percentile summary

min, p50 through p99, max, mean and stdev per phase across -c N runs. Tail latency, not averages.

--assert-status --max-ttfb

CI and cron ready

Exits non-zero when a status or phase budget is breached. Drops straight into pipelines.

--expect-body --expect-regex

Body validation

Fail when the body is wrong, not just the status code. Catches soft-error 200s.

<DNS-FAIL> <TLS-FAIL> <TO>

Failure markers

Printed in exactly the column that broke, so you see where it failed, not just that it did.

auto

Self-explaining TLS failures

Verify reason plus the offending certificate, read off the connection that failed. No re-run.

--tls-info

Certificate inspection

Issuer, SANs and days until expiry, colored as the deadline gets close.

-S

Streaming and SSE

Times every chunk as it arrives. CHUNKS, AVG_GAP and MAX_GAP show stalls mid-stream.

-S --stats

Gap percentiles (ITL)

Distribution over every inter-chunk gap. Meaningful at -c 1, and it spots proxy batching.

-P / -p IP

IP pinning

Hold every run on one backend instead of measuring a different one per DNS round-robin.

--server-hints

Per-request provenance

Which server, edge, CDN or backend answered each request, flagged constant or varied.

--show-headers --capture-header

Header capture

Cache HIT/MISS verdict, plus any response header you name, tracked per request.

REDIRECT

Redirect accounting

Hop count and time in their own column, so TOTAL_TIME always adds up.

--http2

HTTP/2

The PROTO column shows what was actually negotiated: h1, h1.0, h2 or h3.

-b -j --show-cookies

Cookies and sessions

Cookies persist across every run in an invocation. Test login flows and session affinity.

--capture-on failed

Output capture

Full responses written to disk for the runs that matter, without moving the timings.

-H -d -X -4 -6

curl-compatible flags

Auth headers, POST bodies, methods, IP family. Your muscle memory already works.

--prometheus

Prometheus exporter

Re-probes on every scrape. Helm chart and ServiceMonitor included.

ghcr.io

Runs as a container

Probe from a pod, CI job or bastion inside the network you're debugging. No pycurl build.

catppuccin

Color that means something

Cool blues for fast, warm peach and red for slow. Auto-off when piped.

Install

Run it anywhere.

A single Python script on top of pycurl. Or skip the build and use the image.

local

# pycurl must match libcurl's TLS backend
git clone https://github.com/bytebeast/check-endpoint.git
cd check-endpoint
python3 -m venv ~/.venvs/check-endpoint
source ~/.venvs/check-endpoint/bin/activate
PYCURL_SSL_LIBRARY=openssl pip install pycurl
./check-endpoint.py -c 10 --stats https://example.com

docker

# nothing to install beyond Docker
docker run --rm -it \
  ghcr.io/bytebeast/check-endpoint:3 \
  -c 10 --stats https://example.com

kubernetes

# probe from inside the cluster
kubectl run check-endpoint --rm -it -q --restart=Never \
  --image=ghcr.io/bytebeast/check-endpoint:3 \
  --command -- sh -c 'sleep 2; exec check-endpoint "$@"' \
  -- --tls-info https://my-svc.my-ns.svc.cluster.local/health
